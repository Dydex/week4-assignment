# Week 4 Assignment – Smart Contract Deployment

This repository contains my Week 4 assignment, where I successfully deployed **four smart contracts** to live testnet networks using modern Ethereum development tools.

---

## Objective

The goal of this assignment was to:

- Compile contracts using Foundry and Hardhat
- Configure RPC connections for a testnet
- Deploy contracts to a live blockchain
- Verify deployed contracts on a block explorer
- Understand real-world deployment workflows

---

## 🛠 Tech Stack

- **Solidity** `^0.8.33`
- **Foundry (forge)**
- **Hardhat**
- **Node.js**
- **Testnet Network** (Lisk / Arc)
